# Statistická volební data pro program MarkO
Otevřená data [https://csu.gov.cz](Českého statistického úřadu) z portálu [https://volby.cz](volby.cz).
Ve složkách se nachází pouze nezbytné minimum, nikoliv kompletní statistická data za dané volby. Veškeré údaje jsou v nezměněné podobě. Složky také obsahují nestatistické soubory, které slouží pro potřeby programu MarkO.
